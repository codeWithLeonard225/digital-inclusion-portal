Assistive Technology Guide

Learn how screen readers, voice controls, and software accessibility features make technology usable for everyone.

Lesson 1: Screen Readers

Screen readers convert on-screen text into synthesized speech or Braille output for blind or visually impaired users.

  • NVDA: A free and open-source screen reader for Windows.
  • JAWS: A popular screen reader used by many computer users.
  • VoiceOver: Apple's built-in screen reader.
  • Windows Narrator: A screen reader included with Windows.

Lesson 2: Speech Recognition

Speech recognition software enables users to control computers and enter text using their voice.

  • Control the computer using voice commands.
  • Dictate text without using a keyboard.
  • Navigate applications using voice.
  • Perform hands-free computer tasks.

Lesson 3: Keyboard Accessibility

  • Tab: Move forward between controls.
  • Shift + Tab: Move backward between controls.
  • Enter: Activate a selected link or button.
  • Space: Activate certain buttons and controls.

Lesson 4: Accessibility Settings

Modern operating systems offer built-in display and motor accommodations, such as High Contrast Mode, Screen Magnifiers, Sticky Keys, and Text Resizing.
