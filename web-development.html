Web Development Fundamentals

Build accessible, responsive websites using semantic HTML, CSS, and ARIA markup.

Lesson 1: HTML Basics

HTML (HyperText Markup Language) provides the structure of web pages.

  • Use semantic elements such as <header>, <nav>, <main> and <footer>.
  • Use headings in a logical order.
  • Use descriptive links.
  • Add labels to form fields.

Lesson 2: Styling with CSS

CSS (Cascading Style Sheets) designs layout, typography, and color. Ensure adequate color contrast (at least 4.5:1 ratio for standard text) so content is legible for low-vision users.

Lesson 3: Accessible Web Design

Accessible web design ensures people with diverse abilities can read, interact with, and navigate websites. Always include image alt attributes, explicit form <label> tags, and clear focus indicators.

Lesson 4: Understanding ARIA

WAI-ARIA (Accessible Rich Internet Applications) provides additional information to assistive technologies when standard HTML is not sufficient.

  • aria-label provides an accessible name.
  • aria-expanded indicates whether a control is expanded or collapsed.
  • aria-live can announce dynamic content changes.
